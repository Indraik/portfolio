## 🚀 Running Locally

You can run this project directly in any browser:

```bash
# Clone the repository
git clone https://github.com/Indraik/portfolio.git
cd portfolio

# Open index.html in default browser (Windows)
start index.html

# Or serve via Python HTTP server
python -m http.server 3000
```
Visit `http://localhost:3000` to view the live site.
